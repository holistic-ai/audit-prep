# Holistic AI audit preparation

A skill for your coding agent. It reads your repo and drafts the answers and the API documentation for a Holistic AI bias audit of a hiring or promotion system. Nothing leaves your repo: the agent writes an `audit-prep/` folder, and you upload it in the Holistic AI client app, where you check every answer before you save it.

## Install

```sh
npx skills add holistic-ai/audit-prep
```

This works with Claude Code, Codex, Cursor and other agents that read skills.

## Use

Ask your agent:

> Follow the holistic-audit-prep skill to write the Holistic AI audit preparation pack for this repo.

The agent never copies credential values, personal data or team names into the pack. Upload `audit-prep/audit-prep.json` and the API documentation file it names on the intake page of your audit.
